# v0.2.0-learn validation record

Date: 2026-09-10 (Asia/Shanghai)

This record covers the release-candidate working tree based on `learn-version`
commit `ec02a3b`. The immutable source SHA, CI URL, and npm integrity value must
be added to the GitHub Release after the release PR is merged and before the
maintainer confirms publication.

No credential values are included in this record.

## Package and runtime gates

- Bun 1.4.0: typecheck, lint, formatting, build, fixture gate, release gate,
  and the complete 462-test suite passed.
- Node.js 22.23.2 and 24.20.0: package smoke, security inspection, and clean
  tarball consumer installation passed.
- `npm pack` produced one `0.2.0` archive with the required JS, declaration,
  source-map, README, LICENSE, and NOTICE files; source and test directories
  were excluded.
- The package consumer installed the archive independently with both Bun and
  npm and exercised every supported public subpath.
- The compatibility release gate reported 59 implemented rows, zero planned
  rows, and zero unrecognized statuses.

## Real LLM and Agent execution

An OpenAI-compatible provider configured through `.env` was used without
logging its credential. The following calls completed against the real API:

- `HelloAgentsLLM.invoke` and streaming (`STREAM_OK`).
- `SimpleAgent` returned the expected arithmetic answer.
- `ReActAgent` emitted a real action, invoked `CalculatorTool`, observed the
  result, and returned `390`.
- `FunctionCallAgent` emitted a native structured tool call, invoked the
  injected weather handler for Beijing, and returned its result.
- `ReflectionAgent` completed initial, reflection, and refinement passes.
- `PlanAndSolveAgent` parsed a real generated plan, executed it, and returned
  the expected result (`3^4 = 81`).

The opt-in `test:integration` smoke was also executed after correcting its
string-return assertion and passed. Protocol-heavy Agent runs require enough
output budget; the successful checks used 256 tokens for ReAct/Plan-and-Solve
and 512 for Reflection.

## Real Hugging Face, evaluation, and RL execution

- Hugging Face access succeeded for `math-ai/aime25` and
  `gaia-benchmark/GAIA` using the configured endpoint and token.
- The official AIME25 test JSONL loaded as 30 records.
- The official GAIA validation Parquet loaded as 165 records (levels 1/2/3:
  53/86/26), including 38 attachment-bearing samples.
- `LocalTransformerEmbedding` ran the real
  `Xenova/all-MiniLM-L6-v2` model; two 384-dimensional vectors were finite.
- The Python bridge was probed with Python 3.12.13, TRL 1.13.0,
  Transformers 5.17.0, Torch 2.14.0, and Datasets 5.0.1.
- A minimal real SFT run completed and wrote model weights.
- A minimal real GRPO run (`sshleifer/tiny-gpt2`, one sample, one epoch,
  accuracy reward) completed through `PythonTrainingBackend` in 13.082 seconds
  and wrote both final and checkpoint `model.safetensors` files. On non-CUDA
  hosts the bridge explicitly selects CPU and disables unsupported fp16/bf16
  flags; this was rechecked with the upstream `use_fp16=true` default and avoids
  unsupported Apple MPS attention/dropout execution.
