# HelloAgents TypeScript v0.2.0-learn

This is the first npm release of the teaching-oriented TypeScript line. Install
it explicitly with:

```sh
npm install @junlang-7/helloagents@learn
```

The npm `latest` tag remains on the independent production-oriented `1.x`
line. This release is published as package version `0.2.0` with dist-tag
`learn`; its Git tag is `v0.2.0-learn`.

## Highlights

- Core LLM abstraction and Simple, Function Calling, Tool-Aware, ReAct,
  Reflection, and Plan-and-Solve agents.
- Tool registry, chains, parallel execution, built-in tools, and teaching
  examples for Chapters 07–11.
- Memory and RAG pipelines, with lazily loaded Qdrant and Neo4j backends.
- Context engineering plus MCP, A2A, and ANP protocol modules.
- Evaluation datasets/evaluators and TypeScript-friendly RL helpers.
- Bun and Node.js 22/24 package support with explicit public subpath exports.
