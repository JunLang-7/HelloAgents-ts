## 🎯 核心公告

**HelloAgents TypeScript v0.2.0 正式发布为「学习版」**。它以 Python
HelloAgents 的 `learn_version` 为教学权威基线，将核心 Agent、工具、记忆、
RAG、协议、评测和 RL 能力忠实移植到 Bun/Node.js。

- ✅ **固定基线**：锁定 Python 提交 `3927c6d1`，避免教学 API 随上游漂移
- ✅ **教学优先**：覆盖 Chapter 07–11 与 Function Calling 示例
- ✅ **运行时兼容**：支持 Bun 1.3.14+ 与 Node.js 22+
- ✅ **真实验收**：真实 LLM/Agent、Qdrant、Neo4j、Hugging Face、SFT 与 GRPO 均已验证
- ✅ **独立发布线**：npm 使用 `learn` tag，不改变生产版 `latest`

---

## 🚀 核心能力

### 1. Agent 与工具体系

- `SimpleAgent`、`FunctionCallAgent`、`ToolAwareSimpleAgent`
- `ReActAgent`、`ReflectionAgent`、`PlanAndSolveAgent`
- 工具注册表、工具链、并行执行器以及计算、搜索、笔记和终端等教学工具
- OpenAI-compatible、Anthropic、Gemini 三类适配器及流式输出

### 2. Memory 与 RAG

- 工作记忆、情景记忆、语义记忆和感知记忆
- SQLite 文档存储，以及按需加载的 Qdrant/Neo4j 后端
- 文档处理、向量检索、GraphRAG、重排、摘要与 `RAGTool`
- TF-IDF、远程 embedding 和 Hugging Face 本地 Transformer embedding

### 3. Context 与协议

- 上下文构建、选择、组织、压缩和 token 预算
- MCP、A2A、ANP 协议模块及对应 Tool 封装
- 可选依赖保持惰性加载，基础包导入不会启动外部后端

### 4. Evaluation 与 RL

- BFCL、GAIA、AIME 数据集与评测器
- LLM Judge、Win Rate 和评测工具
- GSM8K 数据、数学奖励函数、SFT/GRPO Python 训练桥
- 非 CUDA 主机显式使用 CPU，避免 Apple MPS 的 GRPO attention/dropout 限制

## 🔧 安装与验证

### npm

```bash
npm install @junlang-7/helloagents@learn
# 或固定版本
npm install @junlang-7/helloagents@0.2.0
```

### Bun

```bash
bun add @junlang-7/helloagents@learn
```

### 快速开始

```ts
import { CalculatorTool, HelloAgentsLLM, ReActAgent, ToolRegistry } from '@junlang-7/helloagents';

const llm = new HelloAgentsLLM();
const tools = new ToolRegistry().register(new CalculatorTool());
const agent = new ReActAgent({ name: 'assistant', llm, toolRegistry: tools });

console.log(await agent.run('What is sqrt(144)?'));
```
