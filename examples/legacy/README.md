# Legacy (1.x) examples

These demos showcase HelloAgents 1.x-only capabilities that are **not part of
the learn v0.2.0 teaching entrypoint** (#81): Session persistence, Skills,
subagents, TodoWrite/DevLog, file tools and SSE streaming.

They are kept for regression reference and run against the source tree via
relative imports. They are intentionally not packaged: the package `exports`
map only exposes the teaching root and subpath barrels.
