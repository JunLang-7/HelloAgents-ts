## Real LLM and Agent execution

An OpenAI-compatible provider configured through `.env` was used without
logging its credential. The following calls completed against the real API:

- `HelloAgentsLLM.invoke` and streaming (`STREAM_OK`).
- `SimpleAgent` returned the expected arithmetic answer.
- `ReActAgent` emitted a real action, invoked `CalculatorTool`, observed the
  result, and returned `390`.
- `FunctionCallAgent` emitted a native structured tool call, invoked the
  injected weather handler for Beijing, and returned its result.
- `ReflectionAgent` completed initial, reflection, and refinement passes.
- `PlanAndSolveAgent` parsed a real generated plan, executed it, and returned
  the expected result (`3^4 = 81`).

The opt-in `test:integration` smoke was also executed after correcting its
string-return assertion and passed. Protocol-heavy Agent runs require enough
output budget; the successful checks used 256 tokens for ReAct/Plan-and-Solve
and 512 for Reflection.
